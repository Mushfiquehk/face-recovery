# Ask how the user feels before showing the score

The natural place for a Journal Entry is after the result screen, once the user has seen their
Recovery Score. We ask straight after the shutter instead, while the scan is still being scored,
and show the result only once the entry is saved or skipped. Someone just told they look fatigued
will tend to say they feel tired, and Perceived Recovery is only worth comparing with the Recovery
Score and WHOOP Recovery if it was not anchored by one of them. The few seconds of scoring are also
time the user would otherwise spend watching a spinner.

Every entry records whether it was Blind to Score. Entries added later from the result or day
screens, and any edit to an existing entry, are kept but marked as not blind, so the research strand
can choose to use blind answers only.

## Consequences

The first thing a user sees after the shutter is a question, not a number. Only the first scan of a
day asks; a retake does not, even if the user chose "Not now". Perceived Recovery is never blended
into the Recovery Score, for the same reason WHOOP Recovery is not.
